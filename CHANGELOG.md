# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-11

### Added

- `AcurisGeocoding.mount()` with single-line and fielded input and an optional country selector.
- Coordinates, precision tier, point/area badge from `point_coordinate`, approximate warning, OpenStreetMap link.
- No match handling with candidates, `acuris:result` / `acuris:error` events, proxy support.
